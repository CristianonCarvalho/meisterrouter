Configuração · Cadeia de fallback

Cada slot é uma posição da cadeia (nome e política); o cartão colorido dentro dele é o conteúdo (harness, modelo, esforço, custo). Arraste um cartão para outro slot, ou toque num cartão e depois no de outro slot, para trocar o conteúdo dos dois. Editar abre todos os parâmetros da via. + via e + novo nível criam vias.
Protótipo descartável: dados de exemplo, nada é gravado.

Caminho de uma tarefa (simulação)

Mostra por onde uma tarefa passa. O Jev escolhe a via inicial entre as que aceitam a classe da tarefa (aqui você escolhe). Toque numa via para simular que ela falhou (sem créditos, timeout…). A cadeia anda sempre para frente: primeiro as vias do mesmo nível (⇄), depois escala para o nível seguinte (⤹).

⇄ fallback lateral (mesmo nível, outra via) ⤹ escalonamento (próximo nível, normalmente mais caro) contorno âmbar = conteúdo alterado, não salvo
